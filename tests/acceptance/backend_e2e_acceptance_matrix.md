**Scope:** Candidate/user workflow sequence for U7.1 / S13-B03-T01. This matrix maps each required journey stage to existing PostgreSQL-backed or runtime-oriented regression evidence. It is a traceability artifact, not a claim that the entire journey has already been executed as one end-to-end test.

## Overall assessment

- **Existing integration coverage:** Broad, resource-specific PostgreSQL tests exist across every major candidate journey stage listed above.
- **Full end-to-end execution:** **Not yet demonstrated.** The current evidence is a suite of integration tests at stage boundaries, not one orchestrated acceptance run that signs in a candidate and carries the same owned records through profile/preferences/pathway, evidence/import, discovery, evaluation, Punt, CV/package, application tracking, notifications and support.
- **Next work:** Use this matrix to design a deterministic PostgreSQL-backed cross-domain journey test, preserving existing ownership, idempotency, revision and provenance invariants. Keep live-provider smoke tests as explicitly separate gates.
- **Scope boundary:** This matrix covers candidate workflows only. Full Admin control-plane acceptance remains subsequent work.
